## 问题分析

你说得非常对！当前设计存在以下问题：

| 场景 | 问题 | 后果 |
|------|------|------|
| 用户A和用户B应聘同一公司同一岗位 | 共享同一个 `output/公司名/` 目录 | 文件互相覆盖 |
| 用户C针对同一岗位生成两个简历版本 | 文件名相同，后生成的覆盖先生成的 | 旧版本丢失 |

---

## 解决方案

### 核心思路：在路径中加入 `user_id` 和 `timestamp`

**修改 `job_doc_name` 函数**，让每个用户的每次生成都有独立的目录和文件名。

---

### 修改后的 `utils.py` 中的 `job_doc_name` 函数

```python
def job_doc_name(job_details: dict, output_dir: str = "output", type: str = "", user_id: str = None, timestamp: str = None):
    """
    根据职位信息生成标准化的文件保存路径和文件名。
    
    参数:
        job_details (dict): 包含职位信息的字典，必须包含 'company_name' 和 'job_title'。
        output_dir (str): 根输出目录，默认为 "output"。
        type (str): 文件类型标识。
        user_id (str): 用户ID，用于区分不同用户。
        timestamp (str): 时间戳，用于区分同一用户的多次生成。
    
    返回:
        str: 完整的文件绝对路径字符串。
    """
    # 获取公司名称
    company_name = job_details.get("company_name", "")
    if not company_name or company_name.strip() == "":
        company_name = "Jobs"
    
    # 获取职位名称
    job_title = job_details.get("job_title", "")
    if not job_title or job_title.strip() == "":
        job_title = "Position"
    
    # 清理字符串
    company_clean = clean_string(company_name)
    job_title_clean = re.sub(r'[<>:"/\\|?*]', '', job_title)
    job_title_clean = job_title_clean.replace(" ", "_")[:30]
    
    # ===== 新增：构建用户隔离的目录结构 =====
    # 如果没有提供 user_id 和 timestamp，自动生成
    if user_id is None:
        user_id = "unknown"
    if timestamp is None:
        import time
        timestamp = str(int(time.time()))
    
    # 目录结构: output/{company}/{user_id}/{timestamp}/
    doc_dir = os.path.join(output_dir, company_clean, str(user_id), timestamp)
    os.makedirs(doc_dir, exist_ok=True)
    
    # 文件名: {company}_{job_title}_{type}.ext
    doc_name = "_".join([company_clean, job_title_clean])
    
    if type == "jd":
        return os.path.join(doc_dir, f"{doc_name}_JD.json")
    elif type == "resume":
        return os.path.join(doc_dir, f"{doc_name}_resume.json")
    elif type == "cv":
        return os.path.join(doc_dir, f"{doc_name}_cv.txt")
    else:
        return os.path.join(doc_dir, f"{doc_name}_")
```

### 优点

| 问题 | 解决方案 |
|------|----------|
| 不同用户文件混淆 | 按 `user_id` 分目录隔离 |
| 同一用户多次生成覆盖 | 按 `timestamp` 分目录保存所有版本 |
| 版本追溯 | 可以通过时间戳找到历史版本 |
| 数据库关联 | 在 `resume_history` 表中保存 `timestamp` 字段，便于恢复 |

### 数据库同步修改

在 `resume_history` 表中添加 `timestamp` 字段：

```sql
ALTER TABLE resume_history ADD COLUMN generation_timestamp TEXT;
```

保存记录时存储时间戳，加载时根据时间戳定位文件。
