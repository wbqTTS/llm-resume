职位名称：算法工程师
所属部门：研发部

工作地点：北京/上海/深圳/杭州

岗位职责：
负责公司核心业务系统的后端架构设计、开发与优化，确保系统的高可用性、高并发性和可扩展性。

主导数据库建模与性能调优，解决复杂场景下的数据存储与查询瓶颈。

设计和实现高效的 RESTful API 接口，支持前端及第三方合作伙伴的集成。

推进微服务化改造，利用 Docker 进行容器化部署与管理。

参与智能问答、推荐系统等 AI 相关项目的开发与落地。

参与代码审查，提升团队整体代码质量和技术氛围。

任职要求：
计算机相关专业本科及以上学历，2026届应届毕业生或 1-3 年工作经验。

熟练掌握 Python 语言，具备良好的编程习惯和代码规范意识。

熟悉 Spring Boot 或 Flask 等主流 Web 框架，有完整项目开发经验者优先。

熟悉 MySQL、PostgreSQL 等关系型数据库，具备优秀的 SQL 编写能力；熟练使用 Redis 等缓存技术。

熟悉 Linux 操作系统，掌握 Docker 容器化技术。

熟悉 Git 版本控制工具，了解 RabbitMQ 等消息中间件。

具备良好的沟通能力和团队合作精神，对技术有热情，学习能力强。

了解 LangChain、RAG 等 AI 技术者优先。

加分项：
有 ACM/ICPC、CCPC 等算法竞赛获奖经历者优先。

有开源项目贡献或技术博客者优先。

有在线判题系统（OJ）或推荐系统开发经验者优先。

熟悉前端技术（Vue.js/React）者优先。
