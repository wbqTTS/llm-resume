# AI 优化进度原型

这个目录用于隔离验证“AI 优化阶段显示更细的章节级信息”是否可行，避免直接改动主项目后再回退。

## 原型思路

不在并发子线程里直接调用 Streamlit，而是在主线程消费
`concurrent.futures.as_completed(...)` 的结果时，额外触发一个
`section_callback(section_name, data, analysis)`。

这样做有两个好处：

1. 子线程仍只负责计算，不碰 UI，风险低。
2. 主线程能够在每个章节完成时拿到：
   - 章节名称
   - 是否跳过
   - 是否回退
   - 匹配关键词
   - 优化策略
   - 差距分析

如果这个原型测试稳定通过，就说明主项目可以用“可选回调”的方式接入更细的 AI 优化进度展示。
